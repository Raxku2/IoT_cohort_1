## ▤ Chapter Overview

Modern web development relies heavily on CSS frameworks to rapidly build responsive, accessible, and polished user interfaces. This chapter introduces two fundamentally different approaches to styling: **Tailwind CSS** (utility-first) and **Bootstrap** (component-based). 

Rather than detailing the code here, this guide directs you to the official documentation and CDN links so you can start prototyping immediately.

## ▷ Getting Started

**1. Choose your framework:** 
Decide whether your project needs pre-built UI components (Bootstrap) or highly customizable utility classes (Tailwind).

**2. Copy the CDN script/link:**
Follow the links above to grab the `<script>` or `<link>` tags provided by the official documentation.

**3. Paste into your HTML:**
Place the CDN links directly into the `<head>` of your `index.html` file to instantly enable the framework. Read the linked documentation to learn how to apply the classes to your HTML elements.
